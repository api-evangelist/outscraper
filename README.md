# Outscraper (outscraper) — removed

This profile was removed from the API Evangelist network and the [APIs.io](https://apis.io) catalog on 2026-10-05.

**Nobody asked for this removal.** It is a catalog policy decision by Kin Lane, not a request from Outscraper.

APIs.io does not list APIs built on access that a platform's own terms prohibit. Outscraper's core product is
Google Maps and business-data scraping outside Google's own APIs, so it falls under that rule — the same rule
that declined G Maps Crawl (2026-10-03) and Hubertino (2026-10-05). The decision is about what the data access
is, not about the quality of Outscraper's documentation or artifacts, and it is not reversible by publishing
a specification or paying for a listing.

What was removed: `apis.yml` and every artifact in this repository (blogs, plans, pricing, rate limits, FinOps,
MCP, security, scores and screenshots); the provider, API and artifact pages on apis.io and apievangelist.com;
and the provider's rows in every listing, tag, industry, country and score rollup.

Outscraper is recorded on the delisting registry
([`delisted.yml`](https://github.com/api-search/network/blob/main/_data/delisted.yml), `basis: policy`,
`scope: full`, `relisting: 'no'`), which every API Evangelist harvesting and enrichment pipeline consults, so
it will not be re-added automatically.

Questions about this decision: info@apievangelist.com.
